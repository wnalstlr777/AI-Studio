# 히나 Windows 비서 — 2D 모션 전용 에이전트 규칙

이 규칙은 desktop/ 및 shared/hina/ 의 히나 비서 애니메이션 제작·재생·배포 작업에 적용한다.

## 원본 보존
- secretary.png와 greeting.gif 원본을 절대 덮어쓰거나 재제작하지 않는다.
- 새로운 동작은 별도 에셋으로 제작하고 기존 동작은 유지한다.
- 새로운 동작을 추가해도 기존 IDLE 숨쉬기 및 greeting.gif 재생을 중단하지 않는다.

## 크기·정렬 표준
- IDLE 원본 secretary.png를 시각적 기준으로 사용한다.
- 모든 모션은 동일한 화면상 캐릭터 키, 너비 비율, 중심선, 발바닥 기준선에 정렬한다.
- GIF 캔버스 크기가 다르더라도 투명 여백을 포함한 실제 캐릭터 실루엣 크기를 기준으로 비교한다.
- 각 프레임은 고정 캔버스와 동일한 기준점에서 렌더링한다. 상태 전환 시 캐릭터가 커지거나 작아지거나 좌우로 튀면 실패다.
- 이미지 표시에는 object-fit: contain을 유지하고 가로세로 독립 스케일링을 금지한다.

## 변형 금지
- 걷기 모션에서 신체 픽셀을 행/열별로 비선형 워핑하여 늘이거나 압축하지 않는다.
- 몸통·얼굴·옷·팔다리의 형태와 비율을 유지한다.
- 이동 표현이 필요하면 우선 전체 이미지의 강체 이동(translate) 또는 미세한 회전(rotate)을 사용한다.
- 실제 다리 관절 보행이 필요해지면 원본에서 파츠를 분리하여 강체 회전으로 구현한다. 한 장짜리 이미지의 하반신을 고무처럼 휘게 만들지 않는다.
- 걷는 동안 크기 변화(scale)나 가로세로 찌그러짐을 주지 않는다.

## 재생·업데이트
- 반복 GIF는 매번 첫 프레임부터 재생되는지 확인한다.
- 새 에셋을 배포할 때 manifest 버전을 올리고 실제 바이트 크기와 SHA-256을 갱신한다.
- 원격 업데이트가 성공하면 기존 동작을 유지하며 새 모션만 교체한다.
- 간단 수정은 관련 파일만 수정하고, 전체 리팩터링이나 장시간 검수는 피한다.

## 최소 검수
- IDLE → WALK → IDLE, IDLE → GREETING → IDLE 전환 시 실루엣 크기·중심·발 기준점이 일치하는지 확인한다.
- WALK 프레임 사이 늘어짐/찢김/찌그러짐이 없어야 한다.
- 코드·메타데이터 검증과 실제 Windows 화면 검수는 구분해 보고한다.
