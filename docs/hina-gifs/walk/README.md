# 오른쪽 걷기 시안 v3

- 모든 프레임 오른쪽 측면. 정면 좌우 반전 시안 폐기, 상하체 합성 제거.
- 원화 sources/hina/walk/generated-sheet.png 보존. 기존 walk.gif는 변경하지 않음.
- 512×614, 전체 8프레임 높이480, 상단131, 발610, 머리 중심256 기준. 동일 배율 변환만 사용.
- 각100ms, 총800ms 무한 루프. 정지 프레임/추가 지연 없음.
- 전체 프레임 접촉표에서 방향/의상/클립보드/발 교차/경계 자세 확인.
- 디코더에서 크기·높이·발·투명·시간 통과. Chromium 실제 화면 캡처 20회에서 8개 고유 프레임과 19회 전환 검사 통과(browser-playback.json). 자동 검사는 시각적 자연스러움을 보증하지 않는다.
- Windows 앱 미검수. 사용자 요청에 따라 WALK 매니페스트 연결 및 GitHub main 반영. preview.html에서 같은 크기의 IDLE과 비교 가능.
