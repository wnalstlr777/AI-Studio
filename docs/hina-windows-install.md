기존 앱의 원격 업데이트는 애니메이션 파일만 바꾼다. 새 8종 목록을 이해하는 실행 코드를 받으려면
최초 한 번 v1.2를 설치해야 한다. 이후 지원 목록 내의 승인된 에셋 변경은 10분 간격으로 확인한다.

## 8종은 현재 검수 시안

모든 모션 파일은 실제 투명 WebP 프레임이지만, 필기 손과 일부 숨겨진 파츠의 복원이 미완성이다.
`complete:false`이므로 일상 자동 동작은 아직 이 시안들을 선택하지 않는다.

1. QA가 작업/오류 상태가 아닌 기본 대기일 때 설정의 모션 목록에서 각각 선택한다.
2. 반복과 일시정지, 원본 비교 및 기준선을 사용해 확인한다.
3. 지속적인 랜덤 시안 검수는 **자유 이동을 끄고** '랜덤 시안 테스트'를 누른다.
   여덟 시안을 기본 대기와 6~15초 간격으로 재생한다. 설정을 닫거나 '캐릭터 크게 검수'로 본다.
4. QA/오류/걷기 등 상위 상태가 발생하면 검수 재생을 중단하고 해당 상태를 우선한다.
5. '기본 대기 복귀'로 시안 검수를 끝낸다. 기존 인사 GIF도 별도 버튼으로 확인할 수 있다.

QA 연결 오류가 계속되면 설정의 `QA 연결:` 진단을 확인한다. HTTP 한도/권한/시간 초과/네트워크
실패를 구분하고 다음 재시도 시각을 표시한다. 이 경우 검수 목적으로 QA 결과를 성공으로 바꾸지 않는다.

Windows Actions에서 기존 네이티브 입력 회귀와 새 8종 브라우저 검사는 통과했다.
설치 마법사, 사용자의 실제 화면, 새 8종 각각의 네이티브 전환·입력, 트레이/자동실행은 별도 확인 대상이다.
